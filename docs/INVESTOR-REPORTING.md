# Investor reporting — confirmed requirements
Administrators need a list of investors and an individual report for each investor. Investors must see only their own account. Keep current principal balances distinct from dated movements and profit. The intended overview includes contributed capital, external capital withdrawals, net principal, outstanding allocated capital, recovered principal, reusable principal, calculated profit, actually received profit, profit distributions, financed orders, and upcoming repayment expectations.
The initial payment is recovered principal. Posted principal returns must become available before the original installment ends. Do not count reused principal as a new contribution. The business receives no separate profit share.
The initial report implementation exposes existing recorded contributions, withdrawals and manual distribution events by selected date range and calendar month (Asia/Tashkent). It does not yet expose automatic receipt-linked recovered principal, earned profit or forecasted repayment balances. Current allocated/available values are pre-recovery ledger values, not final circulating balances. Event time is record creation time. The report history displays up to 200 entries; aggregates include all matching entries. No live financial data or workbook records are committed.
