# Foundation — draft

This branch contains only a generic application skeleton. It does not implement authentication, payment processing, personal-data collection, business calculations or access control.

## Development
- Use Node.js 20.9 or newer.
- Run `npm install`, `npm run typecheck`, then `npm run build`.
- Use `npm run dev` for local development.

## Next steps
- Confirm requirements and access boundaries.
- Establish a component and token system.
- Design and validate public and protected routes separately.
- Implement server-side authorization before connecting any private data.
- Add database migrations, automated tests and deployment configuration once approved.

No credentials or internal business specifications belong in this public branch.
