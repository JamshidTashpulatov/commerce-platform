Inter (SemiBold 600, Bold 700), static TTF instances from Google Fonts, used to render Open Graph images (`app/og`). Inter covers Uzbek Latin, including ‘ (U+2018) and ʻ (U+02BB), which the font bundled with next/og lacks.
